ETSI COMPLIANCE

Standard: ETSI EN 300 401 Section 8.1.8
Compliance: 100% ✅

Format:
  Byte 0: Extension (0x09)
  Byte 1: [Ext 1-bit][LTO 5/6 bits]
  Byte 2: ECC (8 bits)
  Byte 3: International table ID (8 bits)

LTO Encoding:
  5-bit mode (Ext=0): -16 to +15 half-hours
  6-bit mode (Ext=1): -32 to +31 half-hours
  Valid range: -24 to +28 (-12.0h to +14.0h)
