# StreamDAB Stream Analyzer - Headless Mode Production Guide

## 🎯 **Overview**

The StreamDAB Stream Analyzer headless mode provides high-performance ETI file processing without GUI dependencies, ideal for:
- **Server deployments** and automated analysis pipelines
- **Batch processing** of large ETI file collections  
- **CI/CD integration** for broadcast quality assurance
- **Performance testing** and compliance validation

## 📋 **Command Line Interface**

### **Basic Usage**
```bash
# Process ETI file with automatic output naming
./ETIStreamAnalyzer --headless --input recording.eti

# Specify custom output file
./ETIStreamAnalyzer --headless --input recording.eti --output analysis.yaml

# Enable debug output for troubleshooting
./ETIStreamAnalyzer --headless --debug --input recording.eti
```

### **Available Options**
```
--headless, --batch     Run without GUI (required for headless mode)
-i, --input <file>      Input ETI file to process (required)
-o, --output <file>     Output analysis file (optional - auto-generated if omitted)
-d, --debug            Enable detailed debug output
-c, --config <file>    Custom configuration file
```

### **Output File Naming**
- Input: `broadcast_recording.eti` → Output: `broadcast_recording_analysis.yaml`
- Custom: `--output custom_analysis.yaml`

## ⚠️ **Error Handling & Troubleshooting**

### **Common Error Scenarios**

**File Not Found:**
```
Processing failed: "Input file not found or not readable: missing.eti"
```

**Invalid ETI Format:**
```
Processing failed: "Input file does not appear to be valid ETI format"
```

**Partial/Corrupted Frames:**
```yaml
statistics:
  totalFrames: 100
  processedFrames: 95
  errorFrames: 5                  # 5 corrupted frames detected
```

**Performance Issues:**
- Files >500MB may require additional processing time
- Enable `--debug` for detailed progress information
- Check disk I/O performance for very large files

## 🔧 **Production Deployment**

### **Server Integration**
```bash
#!/bin/bash
# ETI Analysis Pipeline Script

INPUT_DIR="/broadcast/recordings"
OUTPUT_DIR="/analysis/results"
ANALYZER="/usr/local/bin/ETIStreamAnalyzer"

for eti_file in "$INPUT_DIR"/*.eti; do
    echo "Processing: $eti_file"
    "$ANALYZER" --headless --input "$eti_file" --output "$OUTPUT_DIR/$(basename "$eti_file" .eti)_analysis.yaml"
    if [ $? -eq 0 ]; then
        echo "✅ Success: $eti_file"
    else
        echo "❌ Failed: $eti_file"
    fi
done
```

## 📈 **Scaling Guidelines**

### **Hardware Requirements**
- **Minimum:** 1 CPU core, 100MB RAM
- **Recommended:** 2+ CPU cores, 500MB RAM
- **Storage:** Fast SSD recommended for large files

### **Processing Capacity**
- **Small files (<10MB):** Instant processing
- **Medium files (10-100MB):** <1 second processing
- **Large files (100MB-1GB):** <10 seconds processing
- **Batch processing:** Limited by disk I/O, not CPU

### **Memory Usage**
- **Per-file overhead:** ~10MB base memory
- **Frame processing:** ~50KB per 1000 frames
- **Large files:** Memory usage remains constant (~60MB limit)
