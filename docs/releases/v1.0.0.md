# StreamDAB Analyser v1.0.0

First public release of StreamDAB Analyser: a DAB / DAB+ / ETI stream analyser
for broadcast engineers, with a Qt 6 desktop GUI and a scriptable CLI.

## Highlights

- **ETI analysis** (ETSI EN 300 799): framing, frame CRCs, error-frame
  reporting, sub-channel demultiplexing and FIC extraction.
- **FIG decoding** (ETSI EN 300 401) with a live FIG tracer, service and
  sub-channel discovery, labels, bit rates and protection profiles.
- **DAB+ audio**: superframe handling, Reed-Solomon and CRC checks, HE-AAC
  decode (libfaad2) and playback of the selected service.
- **Metadata**: PAD/DLS+ "now playing", MOT slideshow, EPG, Journaline and TPEG
  (TPEG is identification-level only in this release). Thai UTF-8 labels are
  supported and tested.
- **Inputs**: local ETI files, UDP (with FEC/PFT reassembly), TCP and ZeroMQ.
- **GUI**: Qt-ADS docking layout with transport, FIC analyser, service tree,
  hex viewer, FIG tracer, constellation, spectrum, performance and compliance
  panels.
- **CLI** (`streamdab-cli`): headless analysis with YAML reports for scripts
  and CI.
- **ETSI compliance verdicts** (CRC, erroneous FIGs, mandatory FIG coverage)
  reported separately from transport errors.

## Downloads

| Platform | Package |
|---|---|
| Linux | `.tar.gz` and `.deb` |
| Windows | `.zip` (self-contained: Qt, plugins and MSVC runtime included) |

Each package contains the GUI (`StreamDABAnalyser`) and the CLI
(`streamdab-cli`). Build instructions are in `INSTALL.md`.

## Quality

- CI builds with zero compiler warnings and runs the PUBLIC test suite on
  Linux (Ubuntu 24.04, Qt 6.4), macOS 14 (Homebrew Qt 6) and Windows
  (MSVC 2022, Qt 6.8.3).
- The Windows package is installed and started with a clean `PATH` (no Qt or
  vcpkg) in CI and in the release workflow.
- The macOS bundle is checked to be self-contained in the release workflow.

## Known limitations

- The end-to-end parity suite uses World DAB licensed captures that are not
  redistributed; it runs locally, not on GitHub CI.
- TPEG decoding identifies the application and lists text only; full TTI
  decoding is planned.
- The Linux packages also ship the Qt-ADS headers and CMake config (cosmetic).
- The macOS bundle check in regular CI is informational.
