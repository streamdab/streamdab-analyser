TECHNICAL SPECIFICATIONS
================================================================================

FIG 0/14 Format (ETSI EN 300 401 §8.1.5):

Byte 0: Extension field (0x0E)
Byte 1: [6 bits SubChId][2 bits FEC scheme]
Byte 2: [8 bits MSB of Start Address (10-bit)]
Byte 3: [2 bits LSB Start Address][1 bit Form flag][5 bits ...]

IF Short Form (Form bit = 1):
  Byte 4: [2 bits unused][6 bits Table Index]
  Total: 5 bytes (1 extension + 4 data)

IF Long Form (Form bit = 0):
  Byte 4: [3 bits Option][2 bits Protection Level][3 bits unused]
  Byte 5: [8 bits MSB Sub-channel Size]
  Byte 6: [2 bits LSB Sub-channel Size][6 bits unused]
  Total: 7 bytes (1 extension + 6 data)

FEC Schemes:
  0 = No FEC
  1 = FEC scheme 1 (Reed-Solomon)
  2 = FEC scheme 2 (Convolutional)
  3 = Reserved

Validation Rules:
  - SubChId: 0-63 (6-bit)
  - Start Address: 0-863 CUs (10-bit, but DAB frame max = 864 CUs)
  - Sub-channel Size: start + size ≤ 864 CUs
  - Form flag at bit 5 of byte 3 (mask 0x20)
