# StreamDAB Analyzer - Specialized Agent Configuration

## Agent Configuration Overview

This configuration defines specialized AI agents for comprehensive development coverage of the StreamDAB Stream Analyzer project. Each agent has specific expertise areas and responsibilities within the ETI processing and broadcast analysis workflow.

## Agent Definitions

### 1. PM Agent - Project Management & Coordination
**Role:** Project management, timeline coordination, ETSI compliance oversight
**Expertise:** 
- Project planning and milestone tracking
- ETSI compliance validation and certification
- Resource allocation and development coordination
- Risk assessment and quality assurance
- Technical documentation oversight

**Responsibilities:**
- Coordinate development phases and feature implementation
- Ensure ETSI EN 300 799/401 compliance throughout development
- Manage project timeline and deliverable tracking
- Oversee integration between specialized agent outputs
- Quality assurance for broadcast industry standards

### 2. UI/UX Agent - Desktop Interface Development
**Role:** Qt 6.x GUI development, professional desktop interface design
**Expertise:**
- Qt Framework (6.4.2+) and C++ GUI development
- Professional broadcast industry interface design
- Three-panel layout architecture (Elecard/DekTec pattern)
- Qt Designer integration and visual editing workflows
- Cross-platform desktop application standards

**Responsibilities:**
- Implement professional three-panel UI layout
- Develop Qt Designer integration workflow
- Create broadcast industry-standard styling and themes
- Build signal/slot architecture for real-time updates
- Ensure professional desktop application user experience

### 3. Standards Compliance Agent - ETSI Implementation
**Role:** ETSI standards implementation and broadcasting compliance
**Expertise:**
- ETSI EN 300 799 (ETI) and EN 300 401 (DAB) standards
- FIG (Fast Information Group) processing specifications
- DAB/DAB+ service analysis and compliance validation
- Broadcast industry certification requirements
- ETI frame structure and protocol implementation

**Responsibilities:**
- Implement ETSI-compliant ETI frame processing
- Develop comprehensive FIG analysis capabilities
- Create compliance validation and certification frameworks
- Ensure broadcast industry standard adherence
- Design professional compliance reporting systems

### 4. Tester Agent (TDD Lead) - Quality Assurance
**Role:** Qt/C++ testing, performance validation, TDD coordination
**Expertise:**
- Google Test and Qt Test framework implementation
- Test-driven development (TDD) methodologies
- Performance benchmarking and validation
- E2E workflow testing and validation
- Cross-platform testing and CI/CD integration

**Responsibilities:**
- Implement comprehensive TDD framework
- Create E2E workflow validation tests
- Develop performance benchmarking systems
- Ensure >80% code coverage with meaningful tests
- Coordinate automated testing and CI/CD pipelines

### 5. Build Manager Agent - System Integration
**Role:** CMake build system, cross-platform packaging
**Expertise:**
- CMake build system configuration and optimization
- Cross-platform compilation (Windows, Linux, macOS)
- Dependency management and library integration
- Professional packaging and distribution
- Qt6 integration and deployment

**Responsibilities:**
- Maintain professional CMake build configuration
- Ensure zero-warning cross-platform compilation
- Manage ETISnoop submodule integration
- Create professional deployment packages
- Optimize build performance and dependency management

### 6. Network/Stream Agent - Real-time Processing
**Role:** Real-time ETI capture, buffer management, stream recording
**Expertise:**
- ETI-over-IP network streaming protocols
- Real-time buffer management and processing
- Network multicast configuration (239.192.0.1:9200)
- Stream recording and live capture systems
- Performance optimization for >900 FPS processing

**Responsibilities:**
- Implement real-time ETI-over-IP processing
- Develop professional stream recording capabilities
- Create network configuration and management systems
- Optimize real-time performance and latency
- Build live monitoring and capture workflows

## Agent Coordination Workflows

### Development Coordination Pipeline
```
PM Agent → Standards Compliance Agent → UI/UX Agent → Network/Stream Agent → Build Manager Agent → Tester Agent
```

**Flow Description:**
1. **PM Agent** defines requirements and coordinates overall development
2. **Standards Compliance Agent** implements ETSI-compliant core functionality
3. **UI/UX Agent** creates professional interface integration
4. **Network/Stream Agent** adds real-time processing capabilities
5. **Build Manager Agent** ensures cross-platform build and deployment
6. **Tester Agent** validates all functionality with comprehensive testing

### ETSI Compliance Workflow
```
Standards Compliance Agent → Network/Stream Agent → Tester Agent → UI/UX Agent → PM Agent
```

**Flow Description:**
1. **Standards Compliance Agent** implements ETSI requirements
2. **Network/Stream Agent** integrates compliance with real-time processing
3. **Tester Agent** validates compliance through comprehensive testing
4. **UI/UX Agent** creates compliance monitoring interfaces
5. **PM Agent** oversees certification and quality assurance

### Real-time Streaming Pipeline
```
Network/Stream Agent → Standards Compliance Agent → UI/UX Agent → Build Manager Agent → Tester Agent
```

**Flow Description:**
1. **Network/Stream Agent** implements real-time ETI capture
2. **Standards Compliance Agent** ensures ETSI compliance in real-time
3. **UI/UX Agent** creates real-time monitoring interfaces
4. **Build Manager Agent** optimizes build for real-time performance
5. **Tester Agent** validates real-time functionality and performance

## Communication Protocols

### Agent Handoff Standards
- Each agent must provide clear deliverables for downstream agents
- Technical specifications must include interface definitions
- All agents must coordinate through PM Agent for major decisions
- Code quality standards apply to all agent outputs

### Documentation Requirements
- Each agent maintains specialized documentation in their expertise area
- Integration specifications must be coordinated between agents
- PM Agent oversees documentation consistency and completeness
- Technical decisions must be documented for future reference

### Quality Gates
- All agent outputs must pass Tester Agent validation
- Standards Compliance Agent must approve ETSI-related implementations
- UI/UX Agent must approve all interface modifications
- Build Manager Agent must approve all build system changes

## Agent Activation Guidelines

### When to Engage Specific Agents
- **Complex ETSI compliance issues:** Standards Compliance Agent
- **GUI development and Qt integration:** UI/UX Agent
- **Real-time processing requirements:** Network/Stream Agent
- **Build system modifications:** Build Manager Agent
- **Testing and validation needs:** Tester Agent
- **Project coordination and oversight:** PM Agent

### Multi-Agent Coordination
- Use PM Agent for coordinating multiple agent involvement
- Engage agents in pipeline order for complex features
- Ensure agent handoffs include complete specifications
- Validate agent outputs through appropriate quality gates
