## TDD Test Quality Assessment Tasks:

### 1. Test Structure Analysis
- Examine all test files and identify the testing framework used
- Check if tests follow AAA pattern (Arrange, Act, Assert) or Given-When-Then
- Verify each test has a clear, descriptive name
- Ensure tests are focused on single behaviours/responsibilities

### 2. TDD Cycle Compliance Check
- Identify if tests would fail without implementation (Red phase validation)
- Check if tests pass with minimal implementation (Green phase validation)
- Look for signs of proper refactoring without breaking tests
- Flag any tests that might have been written after implementation

### 3. Coverage Assessment
- Analyse test coverage for:
  - Happy path scenarios
  - Edge cases and boundary conditions
  - Error handling and exception cases
  - Business logic validation
- Identify missing test scenarios based on the production code

### 4. Test Quality Metrics
- Check for test independence (no dependencies between tests)
- Verify tests are deterministic (same input = same output)
- Ensure tests run fast and don't rely on external dependencies
- Look for proper use of mocks, stubs, and test doubles

### 5. Code Quality in Tests
- Review test readability and maintainability
- Check for code duplication in test setup
- Verify proper use of test utilities and helpers
- Ensure test data is clear and relevant
